Issues we presented

The problems this project sets out to fix.

The quote hand-off

Today the website form drops quote requests as free text; they’re re-keyed by hand (via 17hats) into Current RMS and never price automatically.

2

Inventory & photography

The catalog needs clean-up into sellable products, and many categories still need consistent photography before they can go live.

3

One coherent, on-brand site

A single elevated storefront that matches the brand and reads as well as the reference site — replacing a fragmented setup.
