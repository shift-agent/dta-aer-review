Categories & fulfillment order

The home page presents twelve categories. The inventory page is built on a different set of six — so the collection reorganizes underneath a visitor moving between them. We understand the twelve to be correct and need that confirmed, so the inventory page can be rebuilt to match and the home page cards can link into it.

Matched against the rental system, the twelve hold 963 products / 2,223 options: Linens 1,298 · Dining / Tabletop 226 · Table & Chairs 195 · Catering Equipment 155 · Lighting 93 · Stages 91 · Dance Floors 44 · Tents 41 · Bar Rentals 34 · Decor 34 · Outdoor / Climate 12.

Two gaps need your call: Pedestals / Columns is on the home page but has no products behind it in the rental system, and Drapery (97 options) exists in the system but belongs to none of the twelve.

Offline inventory plan

Built and proven, not hypothetical: every sync writes a complete new “generation” and nothing goes live until it fully succeeds — if Current RMS is unreachable (as it is right now, see #4), the storefront keeps serving the last one that worked. 3

Category cards — rectangle vs. circle

Rectangle is what’s live on staging now — full-bleed tiles matching the product grid. Circle was the softer, boutique treatment from the original mockups. Rectangle needs no extra crop work per category; circle is a valid call if that softer feel matters more than shipping speed.

Inventory API & quote system

The quote form itself is fixed and live — a leftover gap from an earlier migration meant it wasn’t rendering; it now runs the full four-step flow. Current RMS itself is not authenticating (401) — the key on file is several months old and was already due for rotation. Needs a fresh key generated directly from the Current RMS account, handed off outside email/chat.
